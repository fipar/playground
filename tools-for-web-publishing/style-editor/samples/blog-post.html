The Philosophy of Simple Web Publishing

By Alex Rivera · 6 min read · September 2024

The open web was built on simple, semantic markup. Over the past decade, complexity has exploded, but the beauty of plain HTML remains timeless.

When you start with clean document structure, typography and spacing do the heavy lifting. You don't need heavy frameworks or complicated build pipelines to create stunning reading experiences.

Core Principles

  • Semantic structure: Use tags for what they mean, not how they look by default.
  • Fluid typography: Ensure text scales gracefully across screens of every size.
  • Content first: Design around the words and images, not around the layout container.
"Simplicity is prerequisite for reliability." — Edsger W. Dijkstra

Sample Code Snippet

/* Clean CSS reset */
* {
  box-sizing: border-box;
  margin: 0;
  padding: 0;
}

Pro Tip

A good line-height between 1.5 and 1.7 makes long-form text vastly easier to read.
